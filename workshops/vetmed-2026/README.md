# 动物医学院研究生工作坊：上机数据包

工作坊《大语言模型与智能体在科研中的应用实践》（4 学时）实操 2 用的数据。课上二选一，两个文件夹都下载下来就行。

| 文件夹 | 文件 | 内容 |
|---|---|---|
| `A_药敏/` | `ast_mic.csv` | 某省 6 个猪场 2023–2025 年猪源大肠杆菌的 MIC 原始记录 |
| | `breakpoints.csv` | 课上用的判读标准表 |
| | `数据说明.md` | 背景和每一列的含义 |
| `B_转录组/` | `pam_counts.csv` | PRRSV 感染猪肺泡巨噬细胞的 RNA-seq 原始 read 计数 |
| | `pam_samples.csv` | 样本信息表 |
| | `数据说明_转录组.md` | 实验背景和每一列的含义 |

## 怎么用

1. 页面右上角 **Code → Download ZIP**，解压后把 `workshops/vetmed-2026/` 里的两个文件夹放进桌面上的 `AI实践` 文件夹。
2. 按课前安装指南装好智能体软件，把工作文件夹设为 `A_药敏` 或 `B_转录组`。
3. 从讲义的第 1 步"看数据"开始，先让 AI 描述数据，不要一上来就分析。

## 说明

- 两套都是**教学模拟数据**，量级和趋势参照公开报道生成，数值不能引用。不含真实猪场、畜主或未发表数据，可以交给云端模型练习。
- `breakpoints.csv` 只用于课堂练习。正式研究请对照当年最新版 CLSI M100 / VET01S 或 EUCAST 文件。
